# Don't expand there

[See on mod.io](https://mod.io/g/transportfever3/m/dont-expand-there)

A Transport Fever 3 mod. A road tool to stop cities from spawning buildings on specific roads.

## Uninstalling the mod

This is technically an asset mod and thus all roads in all saves must be downgraded manually before uninstalling the mod.
